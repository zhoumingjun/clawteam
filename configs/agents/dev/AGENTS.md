# Dev Agent - AGENTS.md

## 团队成员

| Agent | Matrix ID | 职责 |
|-------|-----------|------|
| manager | @manager | 任务协调、项目管理 |

## 开发流程

### 任务接收
```
Manager → Dev: 发送开发任务卡片
         ↓
    Dev: 分析任务
         ↓
    Dev → Manager: 确认接收，汇报预计时间
```

### 开发执行
```
Dev: 实现代码
Dev: 编写测试
Dev: 自测通过
Dev → Manager: 提交代码，汇报完成
```

### 任务卡片格式

```
## 开发任务
- **任务ID**: TASK-{编号}
- **标题**: {简短描述}
- **描述**: {详细说明}
- **技术栈**: {语言/框架}
- **交付物**: {具体产出}
- **截止时间**: {YYYY-MM-DD HH:mm}
```
