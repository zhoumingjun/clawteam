# Research Agent - HEARTBEAT.md

## 心跳检查配置

**检查频率**: 每 60 分钟
**触发时间**: 固定时间 + 随机偏移

## 检查项

### 1. 调研任务状态

检查当前调研进度：

```
检查列表:
- 进行中的调研
- 待交付的调研
- 逾期的调研
- 等待响应的调研请求
```

**异常处理**:
- 调研逾期 → 通知 Manager → 说明原因
- 调研请求无响应 → 跟进或升级

### 2. 技术跟踪

检查技术动态：

```
检查列表:
- 关注技术的最新版本
- 安全公告
- 新技术趋势
```

**异常处理**:
- 重要安全公告 → 立即通知 Manager
- 技术重大更新 → 更新技术雷达

### 3. 知识库更新

检查知识库状态：

```
检查列表:
- 过时的文档
- 缺失的文档
- 待审核的内容
```

### 4. PoC 状态

检查概念验证进度：

```
检查列表:
- 进行中的 PoC
- 已完成的 PoC
- 失败的 PoC
```

## 心跳报告格式

```
[HEARTBEAT] {timestamp}
================================
调研任务: 2 进行中, 1 逾期
技术跟踪: 5 技术更新, 1 安全公告
知识库: 2 份过期, 1 份待审核
PoC: 1 进行中, 2 已完成
================================
状态: HEALTHY / NEED_ATTENTION / BLOCKED
```

## 告警阈值

| 类型 | WARNING | CRITICAL |
|------|---------|----------|
| 调研逾期 | > 1 | > 3 |
| 安全公告 | > 0 | > 2 |
| 文档过期 | > 3 | > 5 |
| PoC 失败 | > 1 | > 3 |

## 自动恢复动作

1. **技术更新** → 更新技术雷达 → 通知相关 Agent
2. **文档过期** → 标记并通知负责人
3. **安全公告** → 立即上报 Manager

## 与其他 Agent 的协调

### 与 Manager
- 汇报调研结果
- 请求调研方向
- 上报重要发现

### 与 Arch
- 提供技术评估
- 协作架构选型
- 分享技术趋势

### 与 Dev
- 分享新技术发现
- 推荐开发工具
- 协作 PoC

### 与 QA
- 推荐测试工具
- 分享技术调研

### 与 SRE
- 提供运维新技术
- 讨论可观测性方案
