# SRE Agent - HEARTBEAT.md

## 心跳检查配置

**检查频率**: 每 15 分钟（高频，因运维敏感性）
**触发时间**: 固定时间 + 随机偏移

## 检查项

### 1. 服务健康

检查所有服务状态：

```
检查列表:
- 服务可用性
- 响应时间
- 错误率
- 吞吐量
```

**异常处理**:
- 服务不可用 → 立即告警 → 启动恢复
- 响应时间慢 → 分析瓶颈 → 优化

### 2. 资源使用

检查资源使用情况：

```
检查列表:
- CPU 使用率
- 内存使用率
- 磁盘使用率
- 网络带宽
```

**异常处理**:
- 资源 > 80% → 扩容或优化
- 磁盘 > 85% → 清理或扩容

### 3. 告警状态

检查活跃告警：

```
检查列表:
- 活跃告警数量
- P0/P1 告警
- 告警响应时间
- 未确认的告警
```

**异常处理**:
- P0/P1 告警 → 立即响应
- 告警未确认 > 5min → 升级

### 4. 部署状态

检查最近部署：

```
检查列表:
- 部署成功/失败
- 回滚次数
- 部署时长
```

### 5. 日志异常

检查日志中的错误：

```
检查列表:
- ERROR 级别日志
- 异常堆栈
- 性能警告
```

## 心跳报告格式

```
[HEARTBEAT] {timestamp}
================================
服务状态: 8/8 在线
性能: CPU 45%, Memory 62%, Disk 38%
告警: 2 活跃 (1 P2, 1 P3), 0 P0/P1
部署: 3 成功, 0 失败, 0 回滚
日志: 15 ERROR/h (阈值 20)
================================
状态: HEALTHY / DEGRADED / DOWN
```

## 告警阈值

| 类型 | WARNING | CRITICAL |
|------|---------|----------|
| 服务不可用 | - | 任何服务 |
| CPU 使用率 | > 70% | > 90% |
| Memory 使用率 | > 80% | > 95% |
| Disk 使用率 | > 75% | > 90% |
| 响应时间 P99 | > 500ms | > 1s |
| 错误率 | > 0.5% | > 1% |
| P0/P1 告警 | > 0 | > 2 |

## 自动恢复动作

1. **服务 down** → 自动重启 → 验证 → 告警
2. **资源不足** → 扩容或重启非关键服务
3. **部署失败** → 自动回滚 → 告警
