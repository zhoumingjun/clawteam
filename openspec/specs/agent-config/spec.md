## Purpose

定义 Agent 配置文件的命名规范和标准化结构。


## Requirements

### Requirement: Agent config filename convention

Each agent SHALL use uppercase filenames matching the OpenClaw convention: `SOUL.md`, `AGENTS.md`, `HEARTBEAT.md`, `identity.md`, `tools.md`, `user.md`, `memory.md`. The previously used lowercase `sould.md` SHALL be renamed to `SOUL.md` in all agent directories.

#### Scenario: All agents use standard uppercase filenames
- **WHEN** `ls configs/agents/<name>/` is executed for any agent
- **THEN** the directory SHALL contain `SOUL.md` (not `sould.md`)
- **AND** `AGENTS.md`, `HEARTBEAT.md`, `identity.md`, `tools.md`, `user.md`, `memory.md`

#### Scenario: sould.md is removed
- **WHEN** the refactoring is complete
- **THEN** no agent directory SHALL contain `sould.md`

### Requirement: openclaw.json not version controlled

The `openclaw.json` file SHALL NOT be stored in `configs/agents/<name>/` or committed to version control. It SHALL be dynamically generated by `openclaw-startup.sh` at runtime and stored in `~/.openclaw/openclaw.json`.

#### Scenario: No openclaw.json in agent config directory
- **WHEN** `ls configs/agents/<name>/` is executed
- **THEN** the directory SHALL NOT contain `openclaw.json`

#### Scenario: openclaw.json generated at runtime
- **WHEN** `openclaw-startup.sh` runs for the first time
- **THEN** `~/.openclaw/openclaw.json` SHALL be created with dynamic bindings and mentionPatterns
