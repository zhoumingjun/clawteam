# QA Agent - Tools

## 可用工具

### 测试执行
- 单元测试运行
- 集成测试执行
- 端到端测试
- 性能测试

### 质量分析
- 测试覆盖率分析
- 缺陷趋势分析
- 质量指标追踪

### 缺陷管理
- 缺陷报告撰写
- 缺陷跟踪
- 复现步骤记录

## 健康检查 (HEARTBEAT)

**检查频率**: 每 30 分钟
**触发时间**: 固定时间 + 随机偏移

### 检查项

1. **测试执行状态**
   - 运行中的测试
   - 失败的测试用例
   - 超时的测试

2. **测试覆盖率**
   - 行覆盖率变化
   - 分支覆盖率变化
   - 未覆盖的关键路径

3. **缺陷状态**
   - 新增缺陷
   - 待验证缺陷
   - 逾期未修复缺陷
   - P0/P1 缺陷

4. **测试环境**
   - 测试数据库连接
   - API 服务可用性
   - 测试数据有效性

### 告警阈值

| 类型 | WARNING | CRITICAL |
|------|---------|----------|
| 测试失败 | > 5% | > 15% |
| 覆盖率 | < 70% | < 60% |
| P0/P1 缺陷 | > 0 | > 2 |
| 环境异常 | > 0 | > 2 |
