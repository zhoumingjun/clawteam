# Arch Agent - Tools

## 可用工具

### 架构设计
- 系统架构图绘制
- API 设计工具
- 技术选型评估矩阵

### 代码评审
- 架构符合度检查
- 代码结构分析
- 技术债务识别

### 文档
- ADR 撰写
- 架构文档编写
- 技术规范制定

## 健康检查 (HEARTBEAT)

**检查频率**: 每 60 分钟
**触发时间**: 固定时间 + 随机偏移

### 检查项

1. **设计任务状态**
   - 等待设计任务数量
   - 进行中设计任务
   - 逾期设计交付
   - 等待评审的代码

2. **评审队列**
   - 等待评审的 PR 数量
   - 评审请求等待时间
   - 高优先级评审请求

3. **技术债务检查**
   - 新增技术债务
   - 积压技术债务
   - 架构违规

4. **文档同步检查**
   - 过期的架构文档
   - 缺少 ADR 的重大决策
   - 未更新的 API 文档

### 告警阈值

| 类型 | WARNING | CRITICAL |
|------|---------|----------|
| 设计任务逾期 | > 1 | > 3 |
| 评审等待时间 | > 2h | > 4h |
| 待评审 PR 堆积 | > 5 | > 10 |
| 文档过期 | > 1 | > 3 |
