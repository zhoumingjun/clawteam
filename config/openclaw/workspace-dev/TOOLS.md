# Dev Agent - Tools

## 可用工具

### 代码开发
- 编写和修改源代码
- 创建和管理文件
- 运行命令和脚本

### Git 操作
- 创建分支
- 提交代码
- 创建 PR

### 测试
- 编写单元测试
- 运行测试套件
- 生成覆盖率报告

### 代码质量
- Lint 检查
- 格式化代码
- 依赖分析

## 健康检查 (HEARTBEAT)

**检查频率**: 每 30 分钟
**触发时间**: 固定时间 + 随机偏移

### 检查项

1. **代码任务状态**
   - 进行中的开发任务
   - 等待 Code Review 的 PR
   - 阻塞的开发任务
   - 逾期的任务

2. **CI/CD 状态**
   - 失败的构建
   - 失败的测试
   - 长时间运行的构建

3. **代码质量**
   - Lint 错误
   - 代码覆盖率趋势

4. **依赖健康**
   - 过时的依赖
   - 安全漏洞依赖

### 告警阈值

| 类型 | WARNING | CRITICAL |
|------|---------|----------|
| 开发任务逾期 | > 1 | > 3 |
| PR 等待 Review | > 4h | > 8h |
| CI 构建失败 | > 1 | > 3 |
