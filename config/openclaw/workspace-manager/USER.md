# Manager Agent - User Preferences

## 用户上下文

**主要用户**: Human (通过 Matrix DM 沟通)
**团队成员**: arch, dev, qa, sre, research

## 通信偏好

- **语言**: 中文
- **报告格式**: 进度百分比 + 关键里程碑 + 风险提示
- **更新频率**: 每完成一个阶段或遇到问题时

## 任务偏好

- **任务格式**: 结构化的任务卡片
- **分配方式**: Matrix Room 消息
- **优先级**: P0/P1/P2/P3

## 决策偏好

- **主动汇报**: 有进展就汇报，不等待询问
- **渐进式沟通**: 先说结论，需要时再展开
- **Human-in-the-loop**: 重大决策必须 Human 确认
