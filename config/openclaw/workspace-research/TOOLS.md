# Research Agent - Tools

## 可用工具

### 调研工具
- 技术文档搜索
- 方案对比分析
- 评估矩阵计算

### PoC 工具
- 实验环境搭建
- 基准测试
- 验证结果记录

### 文档工具
- 调研报告撰写
- 技术雷达更新
- 参考资料管理

## 健康检查 (HEARTBEAT)

**检查频率**: 每 60 分钟
**触发时间**: 固定时间 + 随机偏移

### 检查项

1. **调研任务状态**
   - 进行中的调研
   - 待交付的调研
   - 逾期的调研
   - 等待响应的调研请求

2. **技术跟踪**
   - 关注技术的最新版本
   - 安全公告
   - 新技术趋势

3. **知识库更新**
   - 过时的文档
   - 缺失的文档
   - 待审核的内容

4. **PoC 状态**
   - 进行中的 PoC
   - 已完成的 PoC
   - 失败的 PoC

### 告警阈值

| 类型 | WARNING | CRITICAL |
|------|---------|----------|
| 调研逾期 | > 1 | > 3 |
| 安全公告 | > 0 | > 2 |
| 文档过期 | > 3 | > 5 |
| PoC 失败 | > 1 | > 3 |
